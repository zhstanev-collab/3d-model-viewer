📝 Setup Instructions:
  1. Prepare your images: Name them sequentially (e.g., image-1.jpg, image-2.jpg, etc.)
  2. Upload them to a web server or CDN
  3. Replace data-folder with your image URL
  4. Update data-filename-x pattern to match your naming
  5. Update data-amount-x to the number of images you have
  6. Save and refresh the page
